## The challenge

A pediatric dentist needed an online presence that built trust with parents, ranked in local searches and turned visits into appointments.

## The solution

- **100% static** site built with Astro 7: no unnecessary JavaScript and minimal load times.
- **Local SEO**: `Dentist` structured data (JSON-LD), Open Graph metadata and service areas.
- Appointment form validated with **Zod** and a swappable delivery adapter (WhatsApp / mock).
- Custom visual identity with Tailwind CSS v4, respecting `prefers-reduced-motion`.

## Outcome

A lightweight, accessible and easy-to-maintain landing page: every text and data point is edited from config files.
