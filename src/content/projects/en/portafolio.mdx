## The challenge

Showcase my work with an eye-catching site **without sacrificing performance or SEO**.

## The solution

- **Astro** ships static HTML; React only hydrates the interactive islands.
- Departures board with CSS split-flap tiles; a tiny script flips them once on load and respects reduced motion.
- Spanish/English **i18n** with `hreflang`, sitemap, RSS, JSON-LD and Open Graph images generated at build time with Satori.
- Contact form backed by a serverless function using **Resend**.
- **Lighthouse CI** on GitHub Actions so performance never regresses.
