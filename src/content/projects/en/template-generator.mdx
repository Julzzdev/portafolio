## The challenge

Starting every frontend project meant repeating the same Vite, Tailwind and ESLint setup.

## The solution

- **Node.js CLI** (ES Modules) registered as a `generate` command through the `bin` field in `package.json`.
- Interactive prompts with **Inquirer**: pick a template and a project name, with name validation.
- Recursive copy of the chosen template: **Vite + React + Tailwind** or **Vite + Vue + Tailwind**.
- Adding a new template is as simple as creating a folder in `templates/`: the menu is built by reading that directory.
