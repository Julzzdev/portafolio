## El reto

Mostrar mi trabajo con un sitio atractivo **sin sacrificar rendimiento ni SEO**.

## La solución

- **Astro** genera HTML estático; React sólo se hidrata en las islas interactivas.
- Tablero de salidas con paletas hechas en CSS; un script mínimo las hace caer una vez al cargar y respeta el movimiento reducido.
- **i18n** español/inglés con `hreflang`, sitemap, RSS, JSON-LD e imágenes Open Graph generadas en build con Satori.
- Formulario de contacto sobre una función serverless con **Resend**.
- **Lighthouse CI** en GitHub Actions para que el rendimiento no se degrade.
