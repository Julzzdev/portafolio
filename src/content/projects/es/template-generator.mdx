## El reto

Empezar cada proyecto frontend implicaba repetir la misma configuración de Vite, Tailwind y ESLint.

## La solución

- **CLI en Node.js** (ES Modules) que se registra como comando `generate` mediante el campo `bin` de `package.json`.
- Preguntas interactivas con **Inquirer**: elegir plantilla y nombre del proyecto, con validación del nombre.
- Copia recursiva de la plantilla elegida: **Vite + React + Tailwind** o **Vite + Vue + Tailwind**.
- Agregar una plantilla nueva es tan simple como crear una carpeta en `templates/`: el menú se arma leyendo ese directorio.
